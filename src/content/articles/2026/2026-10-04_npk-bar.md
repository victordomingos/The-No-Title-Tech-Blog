Summary: npk-bar is a small open source mod that shows the context window, the usage limits and the progress of the current work just above the Claude Code prompt.

Yesterday, Anthropic launched mods for Claude Code, small plugins that hook into Claude Code itself. The newsletter that announced them showed, as an example, a bar above the prompt with the context window usage, and I decided to take that idea a bit further.

![npk-bar just above the prompt in the Claude desktop app]({static}/images/2026/npk-bar-in-window.png)

*npk-bar* is a small panel that sits just above the prompt and shows how full the context window is and how much of the 5-hour and weekly usage limits you have used, with colours that warn you when you are going faster than an even pace. It also reads the progress estimates written by a skill I was already using, to show how far along the validation, the session and the project are.

It works both in the desktop app, as ring gauges, and in the terminal, as text.

![npk-bar in a terminal]({static}/images/2026/npk-bar-terminal.png)

It was written by Claude, under my guidance and supervision.


### Get it now!

npk-bar is open source, released under the MIT licence. Just clone the repository and link the mod into your Claude Code skills folder, as explained in the [README](https://github.com/victordomingos/npk-bar/blob/main/README.md). It needs Claude Code v2.1.287 or later.

I hope it can be useful to you too. Please feel free to fork it and come up with your own variations.
