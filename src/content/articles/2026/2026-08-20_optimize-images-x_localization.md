Summary: Optimize Images X, the multi-platform desktop application that helps you reduce the file size of your images on macOS, Windows and Linux, has just been updated to version 2.2.0. This new version adds full internationalization support with some initial translations, plus a handful of minor UI adjustments.

Optimize Images X can now be used in languages other than English. A new **Language** option has been added to the General tab in the settings window, letting you pick your preferred display language. The application will use it immediately.

Initial translations are already in place for a small number of languages. A word of caution: some of them were generated with the help of an AI and then verified by a human, while others are fully human-written. They are all usable, hopefully, but a native speaker's eye may still catch some incorrections or awkward terms. If you notice anything, or if your language is missing entirely, please feel free to open an issue or submit a pull request with the correct translation. As usual, your contribution is very welcome.

Alongside the i18n work, a few minor UI adjustments were made to keep things tidy as the interface grew.

Just `pip install optimize-images-x` (or `pip install optimize-images-x[dnd]`, to include the optional drag-and-drop support), following the instructions in the docs ([Optimize Images X](https://github.com/victordomingos/optimize-images-x/blob/master/README.md)).
